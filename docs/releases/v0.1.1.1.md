## Kera 0.1.1.1: a download for the NVIDIA DGX Spark

**What this is.** Version 0.1.1.1, open source (Apache 2.0). It adds a download for the NVIDIA DGX Spark and the other
GB10 machines, and teaches Kera's setup about them. Everything in 0.1.1 is unchanged. Kera has not been run on a
Spark yet: the download is built and its CPU side tested on the same kind of ARM processor, and the Spark's own
measurements come once there is one to run them on (`docs/STATUS.md`).

**New**

- **The DGX Spark download** (`kera-v0.1.1.1-linux-arm64-cuda.tar.gz`): Kera for Linux on ARM with NVIDIA's CUDA,
  built for the GB10's graphics chip. Chat, pictures, music, video and speech all use the graphics chip. It uses the
  CUDA 13 libraries DGX OS comes with; without them Kera runs on the CPU and says why.
- **Setup knows a Spark.** It sees that the CPU and graphics chip share the 128 GB and lets a model use about 110 GB
  of it. It says, in plain words, what would free more memory (DGX OS's KHO update, `vm.swappiness=1`, no desktop),
  and changes no system settings itself.
- **Faster loading on a Spark.** The model is read into memory in whole rather than memory-mapped, which measured
  56.3 against 44.7 words a second on a Spark (published measurement; the answers are the same either way).

**Tested** on GitHub's ARM machines: the build for the GB10, and Kera on an ARM CPU like the Spark's (unit tests, the
six tiny model designs giving exactly the reference answers, streamed experts, saved chats, guessing: all passed).

**Not yet:** the picture engine's optional CUTLASS speed-up for NVIDIA chips is off in this download, to be measured on
a Spark first. Speed on a Spark is measured once there is one to run on.
