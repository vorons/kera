   - Make a Tailscale auth key (admin console → Settings → Keys): reusable and ephemeral, and tagged if

   - Give the agent a lasting login key (OpenSSH Server is already on). In an admin PowerShell on the Minisforum:

     ```powershell
     ssh-keygen -t ed25519 -f "$env:USERPROFILE\kera-agent" -C kera-agent   # press Enter twice
     Add-Content "$env:ProgramData\ssh\administrators_authorized_keys" (Get-Content "$env:USERPROFILE\kera-agent.pub")
     [Convert]::ToBase64String([IO.File]::ReadAllBytes("$env:USERPROFILE\kera-agent")) | Set-Clipboard
     ```

     Paste the clipboard into the cloud environment's settings as `KERA_SSH_KEY_B64`. Add
     `KERA_SSH_TARGET` as `<windows user>@<Minisforum's Tailscale name>`. Then delete the `kera-agent`
     file (the private key) from the Minisforum.
   - A new session picks up environment changes.

    **(b)** turn it off by default on the CPU for quantized files: stock's text word for word there, without the
    speed-up. Nothing is changed until you say.
